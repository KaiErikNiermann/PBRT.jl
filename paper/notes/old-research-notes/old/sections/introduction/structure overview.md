	# Versions 
## Draft 
- The background and related works will firstly build upon some of the more low level aspects of interop, this mainly being foreign function interfaces (FFI) and the corresponding machine code specifications known as application binary interfaces (ABIs) 
- We will then shift to the more modern approaches employing various meta techniques largely revolving around the application of various types of abstractions to define different modes of interop 
- (potentially) With this practical understanding we will move one level high in abstraction into the realm of something more theoretical and define how one might formally define an interoperability system by expressing type systems in terms of categorical semantics 
- Finally I will present a motivating practical example which applies various of the practical topics introduced in the background to demonstrate their application in addition contrasting this with various other approaches
- The hope here being to provide not only a broad overview but also compare and contrast this with a practical example so the reader can gain both a broad overview to explore some potentially interesting areas of interoperability, but also understands how various aspects of modern interoperability can have demonstrable real world utility through an applied example and arent only theoretical demonstrations
