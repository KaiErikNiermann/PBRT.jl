# Structural guide 

| Analytical Step | Narrative Role | Purpose                                                                                                                      |
| --------------- | -------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **1. Point**    | **Opening**    | Introduce the core idea or claim of the paragraph. Set up what this section is focusing on.                                  |
| **2. Evidence** | **Challenge**  | Present the complication, problem, or key data: e.g., examples, contrasting cases, or architectural constraints.             |
| **3. Explain**  | **Action**     | Analyze the evidence. Unpack how the evidence demonstrates your point or how the tools approach the challenge.               |
| **4. Link**     | **Resolution** | Tie the analysis back to your broader research question or to the next paragraph’s idea. Build cohesion and signal progress. |

---
# 📚 Analytical Paragraph Phrase Bank

## 1. Point (Opening) — Introduce the Claim
- A key distinction arises when...
- This section examines how...
- Interoperability between X and Y typically involves...
- One major factor influencing tool architecture is...
- It is useful to consider the case of...

## 2. Evidence (Challenge) — Present Examples or Data
- For instance,...
- This becomes evident when observing...
- Consider the example of...
- A well-documented case of this is...
- Empirical/theoretical support for this can be found in...
- This issue is especially pronounced when...

## 3. Explain (Action) — Analyze and Interpret
- This suggests that...
- Such an approach ensures that...
- As a result,...
- This architectural choice reflects a need to...
- The memory model here is crucial because...
- This illustrates a fundamental incompatibility between...

## 4. Link (Resolution) — Relate or Transition
- This distinction underscores the broader trend that...
- Consequently, tools for dissimilar languages must...
- This contrast helps clarify why...
- Understanding this dynamic is essential for...
- As we will see in the next section,...
